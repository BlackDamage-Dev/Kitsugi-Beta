# 03 — Açık kaynak kod araştırması ve arşiv sınırı

8 Kasım 2026'da önceki araştırmadaki mobil/çoklu medya adaylarının sabit commitlerinden seçili Home/keşfet/katalog/kaynak dosyaları ve erişilebilen kök lisans/README'leri toplandı. Kapsam: kod düzeyinde sınırlı inceleme; cihazda çalıştırma yok. TV isteği üzerine yalnız TV odaklı NyanTV **dahil edilmedi**. Her projenin tüm kodunu veya dünyadaki tüm açık kaynak projeleri toplama iddiası yok. `Acik_Kaynak_Referanslari.zip` içindeki `MANIFEST.json`/proje manifestleri SHA-256, orijinal yollar ve sabit commit bilgisini kaydeder; zip yalnız seçilmiş dosyaları içerir, tam repo/build değildir. Başka dosyalara bağımlı olabilir; referans olarak okunur, doğrudan build beklenmez. Film afişleri/markalar ile API verisi lisansı ayrıca değerlendirilir.

## Koddan doğrudan bulgular
1. **Animetail** ([sabit kaynak](https://github.com/Animetailapp/Animetail/tree/1d40ffc07e98c43e4803c7fb0e0dcce237be4141), Apache-2.0): `app/.../presentation/home/HomeFeedScreen.kt` `LazyColumn`, medya filtre state'i ve devam rafını kuruyor; `HomeFeedComponents.kt` medya türü filtresi ve `LazyRow` ile rafı gösteriyor. İlham: tür filtresi + raf. Oradaki filtre/nesne modelleri Kitsugi'nin 7 katalog sözleşmesi değildir; direkt kopya yapılmayacak.
2. **Tadami** ([sabit kaynak](https://github.com/andarcanum/Tadami-Aniyomi-fork/tree/f3af9e7c6ec6dedf9934ef61d4ed37d3b8c067de), Apache-2.0): `app/.../ui/home/HomeHubDiscoverySection.kt` anime/manga/novel tür eşlemesi, ayrı kaynak/öneri modelleri ve cihaz boyutuna duyarlı poster düzeni içeriyor. İlham: tip açık seçik olsun; ama kendi eşlemesini veya kişiselleştirmesini aynen aktarma.
3. **Mangayomi** ([sabit kaynak](https://github.com/kodjodevf/mangayomi/tree/91bda20a9235b64ba2fa5559b1e8fa1205a83988), Apache-2.0): `lib/modules/manga/home/manga_home_screen.dart` kaynak seçimi, popüler/son güncellemeler, filtre ve sayfalama state'iyle source-oriented ekran sunuyor. İlham: tür ve kaynağı bağımsız düşünmek, hata ve boş durumlar. Flutter modeli Kotlin'e kopyalanmaz.
4. **Aniyomi** ([sabit kaynak](https://github.com/aniyomiorg/aniyomi/tree/97414446b8a95994c72dd33c41c971a89d4d25b8), Apache-2.0): anime ve manga browse/source modülleri arşivde, kaynakların yönetimini karşılaştırma amacıyla. Takip hizmetleri ile keşif sağlayıcısı aynı şey değil.
5. **Anisu** ([sabit kaynak](https://github.com/Ansu216/Anisu/tree/8f03a1a38d0b4349e7c61ad6b073baf8dcd24564), GPL-3.0): `ui/home/HomeScreen.kt`, `HomeViewModel.kt`; Home/hero/sezon fikirleri için. **Kod alınmayacak**, yalnız inceleme; GPL için önce uyumluluk değerlendirmesi gerekir.
6. **AniSync** ([sabit kaynak](https://github.com/Marco-9456/AniSync/tree/42421dae9070d9de97f452ed7d1b2d5790aa459e), GPL-3.0): AniList odaklı keşif; arşivde seçili dosyalar. Yalnız inceleme.
7. **Bangumi Multiplatform** ([sabit kaynak](https://github.com/xiaoyvyv/bangumi/tree/c0fceddd9c19678536fc8b84d786c3307ec8d2d7)): `features/main-tab/home/.../HomeScreen.kt` ve alt sayfaları Bangumi gezintisi için referans. README GPL-3.0 diyor, GitHub API lisansı tanımlayamadı ve bu commit ağacında kök lisans dosyası bulunamadı. **Lisans belirsizliği çözülmeden kod/asset alınmaz.**
8. **ShikiApp** ([sabit kaynak](https://github.com/pewaru-333/ShikiApp/tree/6f502320a39aa01d9494494ca7f0645c21f9d756), GPL-3.0): `CatalogScreen.kt`, `CatalogViewModel.kt`, `CatalogState.kt` ve kaynak repository arayüzleri. Yalnız Shikimori katalog mantığı için referans.
9. **Yamtrack** ([sabit kaynak](https://github.com/FuzzyGrim/Yamtrack/tree/387274467e771845cf84fe3ceb1b249ad8405e41), AGPL-3.0) çoklu medya için sınırlı örnek; web, mobil Compose değil. Sadece seçili kodlar.
10. **Shukofukurou** ([sabit kaynak](https://github.com/Atelier-Shiori/Shukofukurou/tree/35b2c0deed4c7b9d4c2734709ef95ad48f8f38ac), BSD-3-Clause): seçme kuralı yalnız kök belge ve lisansı buldu; **ilgili keşif kodu toplanmadı**. macOS ağırlıklı olduğu için yalnız düşük öncelikli çoklu servis karşılaştırması; kaynak kimlik eşleme algoritması incelenmedi.

GitHub arşivleri 85 MB sınırını aşan Mangayomi, Bangumi ve ShikiApp için yalnız belirli dosyalar GitHub içerik API'sinden alındı; diğerlerinde seçici çıkarım yapıldı. İsim/klasör bazlı seçim ilgili her dosyayı garanti etmez; `REFERENCE_MANIFEST.json` her dosyanın tam yolunu gösterir. GitHub URL ve commitlerle eksikler gerektiğinde tamamlanabilir. Bağımlı kodların yokluğu doğaldır.

## Lisans ve kullanma kuralı
Tasarım/etkileşim fikrinden esinlenerek **Kitsugi'ye özgün Kotlin/Compose** yazılacak. Üçüncü taraf kod/asset alınacaksa önce proje ve dosya lisansı, bağımlılık, telif, NOTICE, değişiklik açıklaması, kaynak/dağıtım şartları ve Kitsugi'nin kendi lisans uyumu ayrı denetlenir. GPL/AGPL dosyaları sırf açık kaynak diye uygulamaya kopyalanmaz. Referans zip'inde orijinal lisans ve README mevcutsa korunmuştur; Bangumi istisnası yukarıda. Bu hukuki görüş değildir.
